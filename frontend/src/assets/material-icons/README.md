# Material Icons

24px filled SVG path data from Google's
[Material Design Icons](https://github.com/google/material-design-icons/tree/master/src/action):
`account_circle`, `trending_up`, `euro_symbol`, `event`, and `assignment`.

Distributed under the [Apache 2.0 license](LICENSE). The player section navigation
renders these local paths as inline SVGs with `currentColor` to follow the theme.
