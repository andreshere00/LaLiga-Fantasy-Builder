# Material Icons

24px filled SVG path data from Google's
[Material Design Icons](https://github.com/google/material-design-icons/tree/master/src/action):
`account_circle`, `trending_up`, `euro_symbol`, `event`, `assignment`, `groups`, `bar_chart`,
`medical_services`, `local_offer`, `swap_horiz`, `chevron_right`, `edit`, `close`, and `flash_on`.

Distributed under the [Apache 2.0 license](LICENSE). The player and club section navigation and the player action dialogs
render these local paths as inline SVGs with `currentColor` to follow the theme.
